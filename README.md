# Abhijeet Sonune — Portfolio

Personal portfolio site for Abhijeet Sonune, Business Analyst & Data Analyst.

**Live site:** _add your Vercel link here once deployed_

## What's in here

- `index.html` — the entire site (HTML, CSS, and JS in one file, no build step needed)
- `Abhijeet_Sonune_Resume.pdf` — downloadable resume, linked from the site

## Features

- Profile, experience, projects, education, and certifications pulled from my resume
- An interactive command console (press `/` on the site) for exploring the page by typing things like `skills`, `projects`, or `contact`
- A live feed under Projects that pulls my latest repos directly from the GitHub API — no manual updates needed when I push a new repo
- One-click "Save contact" button that downloads a `.vcf` file
- Fully responsive, no external framework or build tools required

## Tech

Plain HTML, CSS, and JavaScript. Fonts via Google Fonts (Fraunces, Inter, JetBrains Mono). No dependencies, no `npm install` — just open `index.html` in a browser.

## Running locally

Just open `index.html` in any browser. That's it — there's no server or build step.

## Deploying

This repo is set up to deploy on [Vercel](https://vercel.com) with zero configuration:

1. Import this repository at [vercel.com/new](https://vercel.com/new)
2. Click **Deploy** — no settings need to change
3. Vercel gives you a live URL, and redeploys automatically every time this repo is updated

## Updating content

All content lives directly in `index.html` — search for the relevant section (experience, projects, education, etc.) and edit the text in place. To swap the resume, replace `Abhijeet_Sonune_Resume.pdf` with a new file of the same name.
